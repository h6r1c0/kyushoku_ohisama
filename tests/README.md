# 給食計算の回帰確認

`jsdom` をテスト専用の場所へインストールして実行します（アプリ本体に依存ライブラリはありません）。

```sh
npm install --prefix /tmp/kyushoku-verification jsdom@30.0.1
NODE_PATH=/tmp/kyushoku-verification/node_modules node tests/regression.cjs
```

検証対象：5歳児・大人の例外人数／保存復元、米・おかゆ、学童の食事、メイン食材・余り、切り分け4枠、乾物の食事・おやつ・少なめ、ヘルプ生成とID重複、保存済みルールと未設定値の保持、新規初期データの追加と削除済みデータの復活防止。

保存済みの `null` は意図的な未設定か判別できないため維持します。ひじき・切り干し大根の食事量が未設定の場合、確認済みの量を設定するボタンを表示します。新規利用時は5g／10gを初期設定します。

## 実ブラウザでの自動確認

`tests/mobile.cjs` は、GitHub Actionsの独立したChromiumで320px・375px・768px幅の操作と横はみ出しを確認します。公開中のアプリ・実利用者の保存データには触れません。

例外人数、切り分け枠、乾物のモード、食材の追加・削除、基本人数・最大人数の保存復元をUI経由で操作します。全ヘルプのカード画像と `report.json` は `meal-mobile-verification` 成果物に7日間保持します。画像撮影時だけスクロール領域を展開し、全文を確認可能にします。画面幅の検査は展開前の実際の表示で行います。

## 公開前の確認

- 320px・375px・768px幅で、本体・全ヘルプのはみ出し、文字、説明マーカー、画像表示を確認する。
- 実画面で「その他」→入力→通常人数への復帰、学童ON/OFF、アコーディオン排他、切り分けの境目指定、各編集画面の保存・追加・削除を確認する。
- 正式PNGの透過・縦横比と、ロゴの表示サイズを確認する。
- 上記を通過してからmainへ反映し、GitHub Pagesの配信内容との一致を確認する。

DOMテストだけで視覚確認済みとはしません。自動操作と成果物の目視確認を組み合わせます。実機iPhoneの濡れた手での操作性まで保証するものではありません。
